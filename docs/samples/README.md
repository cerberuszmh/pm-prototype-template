# PM 脱敏成品样例包

## 1. 样例定位

本目录提供一套可直接对照的虚构项目成品，用于说明 P07、模块 PRD、模块 SRS、严格审查报告和原型评审结论应填写到什么程度。

- 所有组织、人员、业务和数据均为虚构内容，不对应任何真实客户或项目。
- 本目录属于模板通用资产，不属于当前项目正式交付物。
- 启动真实项目时，应复制对应模板生成业务文档，不得直接把本样例改名后交付。

| 项目 | 内容 |
| --- | --- |

真实项目的正确使用方式：

1. 先阅读本目录样例，理解成品深度和跨文档引用方式。
2. 触发对应 SKILL，由 AI 依据真实业务输入和正式模板生成新文档。
3. 将新文档保存到正式归档目录；不得直接编辑本目录样例作为业务交付物。

## 5. 对照重点

- P07 只维护项目级背景、权限、非功能要求、里程碑及 §9～§12 对齐决策段。
- 模块 PRD 只维护业务背景、业务流程、业务规则和业务级验收。
- 模块 SRS 是字段类型、控件、校验、状态规则、异常提示和技术 AC 的唯一权威源。
- PRD 与 SRS 通过具体章节互相引用，不重复维护同一技术规格。
- 原型评审结论必须以前一阶段无 P1/P2 遗留为前置条件。

## 6. 使用边界

本样例只演示一模块、一个列表页的最小闭环。复杂项目仍需根据真实范围补充产品发现成果、模块间依赖、流程说明、测试用例和开发交接数据字典。
