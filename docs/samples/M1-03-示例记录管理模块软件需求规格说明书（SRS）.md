## 4. 总体说明

> **业务背景与模块目标**：见 PRD §3～§5。

- **系统目标**：使用 Vue 3 与 Ant Design Vue 实现可运行的单页原型，并使字段、状态和反馈与本 SRS 一致。
- **关键约束**：
  - 查询条件采用编辑态与已提交态分离，输入过程不触发筛选。
  - 创建时间为默认排序字段，按时间倒序展示。
  - “已归档”为不可逆终态。
- **外部依赖**：当前原型只依赖本地 Mock 和共享枚举，无真实接口依赖。

## 5. 功能规格

### 5.1 示例记录查询

#### 5.1.1 功能描述

- **功能目标**：按名称、状态、分类和创建时间筛选示例记录，并支持一键恢复全量列表。
- **使用角色**：记录管理员、业务评审人。
- **入口位置**：左侧菜单“示例模块”→“示例列表”，路由 `/example/list`。
- **前置条件**：页面与本地 Mock 数据加载完成。

#### 5.1.2 页面与字段

**筛选字段**

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 名称 | `a-input` 文本输入 | 否 | 支持模糊匹配；宽度 200px；可清空 |
| 状态 | `a-select` 单选下拉 | 否 | 选项来自 `EXAMPLE_STATUS`；宽度 200px；可清空 |
| 分类 | `a-select mode="multiple"` 多选下拉 | 否 | 选项来自 `EXAMPLE_CATEGORY`；宽度 200px；可清空；选项超出宽度时折叠为 `+N`；占位文案“请选择分类” |
| 创建时间 | `a-range-picker` 日期范围 | 否 | `value-format="YYYY-MM-DD"`，按天选择；宽度 260px；占位文案“开始日期”“结束日期” |
| 展开 / 收起 | `a-button` 链接按钮 + 方向图标 | — | 位于“查询”左侧；全部筛选条件与按钮能排成一行时不显示；放不下时收起态只显示第一行容纳得下的条件（至少一个），可用宽度变化时实时重算；被收起的条件照常参与筛选 |
| 查询 | `a-button` 主按钮 | — | 点击后提交当前筛选条件 |
| 重置 | `a-button` 默认按钮 | — | 清空编辑态和已提交态条件，并恢复为收起态 |

#### 5.1.3 处理逻辑

1. 用户修改名称、状态、分类或创建时间时，只更新筛选编辑态，不改变当前列表。
2. 用户点击“查询”后，将名称去除首尾空格，并把名称、状态、分类、创建时间复制到已提交态。
3. 列表按已提交态执行名称模糊匹配、状态精确匹配、分类命中任一匹配和创建时间范围匹配，四项条件取交集。
4. 创建时间范围匹配只比较 `createTime` 的日期部分，起止两天均包含在内。
5. 用户点击“重置”后，同时清空两套条件并恢复全量列表。
6. 筛选完成后按 `createTime` 倒序排列。
7. 用户点击“查询”或“重置”后，分页回到第 1 页，并清空已选记录（见 §5.6.3）。

#### 5.1.4 状态与规则

| 规则项 | 说明 |
| --- | --- |
| 查询触发 | 仅点击“查询”后应用筛选条件 |
| 名称匹配 | 忽略英文字母大小写的包含匹配 |
| 分类匹配 | 选中多个分类时，记录分类命中其中任一即展示 |
| 时间范围 | 起止日期均包含整天；未选择范围时不按时间筛选 |
| 空条件 | 名称为空且状态、分类、创建时间均未选择时展示全部记录 |
| 默认排序 | `createTime` 从新到旧 |
| 分页与选择复位 | 查询、重置后回到第 1 页并清空已选记录；翻页不清空已选记录 |

#### 5.1.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 无匹配记录 | 表格展示 Ant Design Vue 默认空状态 | 无额外 Toast |
| 名称仅含空格 | 查询时按空名称处理 | 无额外 Toast |

### 5.2 示例记录新建与编辑

#### 5.2.1 功能描述

- **功能目标**：在近全屏弹窗内创建或编辑示例记录，或在标准尺寸弹窗内快速编辑示例记录，并可通过只读弹窗查看记录。
- **使用角色**：记录管理员；只读查看另对业务评审人开放。
- **入口位置**：列表卡右上角“新建”按钮；记录行操作列“编辑”按钮（近全屏弹窗）与“快速编辑”按钮（标准尺寸弹窗），两个按钮从左到右排列，其右侧为“删除”按钮（见 §5.5）；记录行名称链接（查看弹窗）。
- **前置条件**：用户进入示例列表页面。

#### 5.2.2 页面与字段

**列表展示字段**

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 编号 `id` | 只读文本 | — | 新建时由 `nextExampleId()` 生成，格式为 `EX-2026-NNNN` |
| 名称 `name` | 链接文本 | 是 | 使用统一链接样式；点击打开「查看示例记录」只读弹窗 |
| 分类 `category` | 文本 | 是 | 位于名称列之后，宽度 120px；按 `EXAMPLE_CATEGORY` 显示中文名称；查看弹窗同步展示 |
| 所属分组 `groupKey` | 文本 | 是 | 位于分类列之后，宽度 240px；显示完整路径，如“华东区域 / 上海分部 / 浦东站点”；查看弹窗同步展示；示例列表不提供按所属分组筛选 |
| 状态 `status` | Tag | 是 | 标签和值来自 `EXAMPLE_STATUS` |
| 创建时间 `createTime` | 日期时间文本 | 是 | 新建时取本地当前时间，格式 `YYYY-MM-DD HH:mm:ss` |

**新建与编辑表单字段**

| 字段/控件 | 控件类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 名称 | `a-input` | 是 | 最大 50 字；失焦时校验；占位文案“请输入名称”；仅含空格视为未填写；保存时去除首尾空格 |
| 分类 | `a-select` 单选 | 是 | 选项为“通知公告”“活动资讯”“制度文件”（`EXAMPLE_CATEGORY`）；选择变化时校验；占位文案“请选择分类” |
| 所属分组 | `a-tree-select` 单选 | 是 | 选项为 `exampleGroupTree`，区域、分部、站点任意层级均可选；下拉默认全部展开，下拉中按节点名称逐级展示；选中后回显完整路径，如“华东区域 / 上海分部 / 浦东站点”，与列表、查看弹窗一致；选择变化时校验；占位文案“请选择所属分组” |
| 状态（新建） | 只读 `a-tag` | — | 默认“草稿”，提示“新建记录默认状态，不可修改”；系统赋值，不做必填校验，不显示必填星号 |
| 状态（编辑非归档记录） | `a-select` | — | 只提供“草稿”“已发布”，归档必须从列表状态入口执行；回填原状态且不可清空，始终有值，不做必填校验，不显示必填星号 |
| 状态（编辑已归档记录） | 只读 `a-tag` | — | 提示“已归档记录状态不可修改”；不做必填校验，不显示必填星号 |

**快速编辑弹窗**

| 字段/控件 | 控件类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 弹窗 | `a-modal` 标准尺寸 | — | 标题“快速编辑示例记录”；桌面 1200×600px，小视口保留四周至少 24px 安全边距；底部“取消”“保存” |
| 名称 / 分类 / 所属分组 / 状态 | 同上方编辑表单 | 同上方编辑表单 | 字段顺序、控件、校验与状态只读规则与“编辑”完全一致 |

**查看弹窗**

| 字段/控件 | 控件类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 弹窗 | `a-modal` 默认宽度 | — | 标题“查看示例记录”；底部仅“关闭”默认按钮，位于右侧 |
| 记录信息 | `a-descriptions` 单列、带边框、小尺寸 | — | 依次展示编号、名称、分类（中文名称）、所属分组（完整路径）、状态（Tag，颜色同 §5.3.4）、创建时间；只读，不提供编辑入口；示例列表与分组列表共用本规格 |

#### 5.2.3 处理逻辑

1. 点击“新建”时清空名称、分类和所属分组，设置状态为 `draft`，并打开“新建示例记录”弹窗。
2. 点击“编辑”时按记录编号回填名称、分类、所属分组和状态，并打开“编辑示例记录”弹窗。
3. 点击“保存”时调用表单校验。
4. 新建校验通过后生成编号和创建时间，将记录加入 Mock 列表。
5. 编辑校验通过后按编号查找原记录并更新名称、分类、所属分组和允许编辑的状态。
6. 保存成功后关闭弹窗；列表重新计算并保持创建时间倒序。
7. 点击“快速编辑”时按记录编号回填名称、分类、所属分组和状态，并打开“快速编辑示例记录”弹窗；保存时的校验与更新逻辑同第 3、5 步。
8. 点击记录名称时打开“查看示例记录”弹窗，展示该记录当前数据；点击“关闭”或右上角关闭图标后关闭弹窗。

#### 5.2.4 状态与规则

| 规则项 | 说明 |
| --- | --- |
| 新建默认状态 | `draft`，中文显示“草稿” |
| 新建编号 | 从 `EX-2026-0019` 起按四位序号递增 |
| 所属分组 | 每条记录必须归属一个分组节点，可为区域、分部或站点任意层级；编辑与快速编辑均可修改 |
| 弹窗关闭 | 关闭时重置字段和校验状态 |
| 两种编辑入口 | “编辑”与“快速编辑”修改同一组字段，仅弹窗规格不同；样例用于对照近全屏与标准尺寸两种弹窗，两个弹窗表单状态互不共享 |
| 归档入口 | 编辑表单不提供“已归档”选项，统一从列表状态标签进入 |
| 归档终态 | 已归档记录的状态只读，不允许回退 |

#### 5.2.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 名称为空或仅含空格 | 阻止保存并展示字段级错误 | `请输入名称` |
| 名称超过 50 字 | 输入层限制长度，校验层再次拦截 | `名称不超过 50 字` |
| 分类未选择 | 阻止保存并展示字段级错误 | `请选择分类` |
| 所属分组未选择 | 阻止保存并展示字段级错误 | `请选择所属分组` |
| 表单校验失败 | 展示 Toast，并平滑滚动到第一个错误字段（近全屏与快速编辑弹窗一致） | `请完善必填项后再操作` |
| 保存成功 | 关闭弹窗并刷新列表 | `保存成功` |

### 5.3 示例记录状态管理

#### 5.3.1 功能描述

- **功能目标**：通过状态 Tag 识别当前状态，并完成允许的状态切换。
- **使用角色**：记录管理员。
- **入口位置**：示例列表“状态”列。
- **前置条件**：记录当前状态不是“已归档”。

#### 5.3.2 页面与字段

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 状态 Tag | `a-tag` | — | 草稿为蓝色、已发布为绿色、已归档为默认灰色 |
| 切换提示图标 | `SwapOutlined` | — | 仅可切换状态显示；字号 11px、透明度 0.7 |
| 状态菜单 | `a-dropdown` + `a-menu` | — | 排除当前状态后展示其他可选状态 |

#### 5.3.3 处理逻辑

1. 草稿或已发布记录显示可点击 Tag 和切换图标。
2. 点击 Tag 后展示除当前状态外的目标状态。
3. 选择草稿或已发布时直接更新状态并反馈结果。
4. 选择已归档时展示二次确认。
5. 用户确认后更新为已归档；用户取消时不改变状态。
6. 已归档记录只展示普通 Tag，不渲染下拉菜单和切换图标。

#### 5.3.4 状态与规则

| 状态值 | 中文文案 | Tag 颜色 | 可切换目标 | 规则 |
| --- | --- | --- | --- | --- |
| `draft` | 草稿 | blue | 已发布、已归档 | 可直接发布；归档需确认 |
| `published` | 已发布 | green | 草稿、已归档 | 可直接退回草稿；归档需确认 |
| `archived` | 已归档 | default | 无 | 不可逆终态 |

#### 5.3.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 选择归档 | 展示二次确认弹窗 | 标题：`确认将「记录名称」切换为「已归档」？`；内容：`归档操作不可逆，请确认是否继续。` |
| 取消归档 | 关闭确认弹窗，不修改记录 | 无额外 Toast |
| 状态切换成功 | 更新状态并展示成功反馈 | `已切换为` + 目标状态中文文案 + `状态` |
| 试图切换已归档记录 | 界面不提供入口；逻辑层直接返回 | 无额外 Toast |

| 创建时间 `createTime` | 日期时间文本 | 格式 `YYYY-MM-DD HH:mm:ss`；宽度 180px |

#### 5.4.3 处理逻辑

1. 进入页面时默认选中“全部”，列表展示全部示例记录，分组树全部展开。
2. 点击分组节点后立即按该节点范围筛选列表，无需点击“查询”。
3. 再次点击已选中的节点时，选中回落到“全部”。
4. 勾选“包含下级”时，节点范围为自身及全部下级节点；取消勾选时仅为节点自身。节点计数与列表筛选使用同一范围口径。
5. 分组搜索按名称包含匹配：节点自身命中时保留其完整子树；仅下级命中时保留到命中节点的上级路径；输入时全部展开。
6. 右侧名称、状态筛选沿用 §5.1.3 的编辑态与已提交态分离逻辑，并与分组范围取交集。
7. 切换分组节点、切换“包含下级”、点击“查询”或“重置”后，分页回到第 1 页。
8. 结果按 `createTime` 倒序排列。

#### 5.4.4 状态与规则

| 规则项 | 说明 |
| --- | --- |
| “全部”节点 | 不属于分组树数据；计数为记录总数，不受“包含下级”影响；搜索时不参与过滤，始终置顶 |
| 节点计数 | 基于全部示例记录统计，不受右侧名称、状态筛选影响 |
| 数据同源 | 与示例列表共用 `exampleList`；示例列表中的新建、编辑（含所属分组变更）、删除和状态切换结果在本页的计数与列表中同步体现 |
| 重置范围 | “重置”只清空右侧筛选卡条件，不改变分组树选中 |
| 窄屏布局 | 视口宽度不超过 992px 时，分组树卡片移到列表上方并占满宽度 |

#### 5.4.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 分组搜索无匹配 | 保留“全部”节点，其下展示简洁空状态 | `无匹配分组` |
| 节点范围内无记录 | 表格展示 Ant Design Vue 默认空状态 | 无额外 Toast |

### 5.6 列表多选与批量操作

#### 5.6.1 功能描述

- **功能目标**：勾选多条示例记录后批量发布、批量归档或批量删除。
- **使用角色**：记录管理员。
- **入口位置**：示例列表首列复选框；列表卡右上角“新建”左侧的“发布”下拉按钮。
- **前置条件**：至少勾选一条未归档记录。

#### 5.6.2 页面与字段

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 行复选框 | `a-table` 受控 `rowSelection`，`row-key="id"` | — | 已归档记录复选框禁用；表头提供全选 |
| 行点击选中 | 行空白区域点击 | — | 等效于切换该行复选框；链接、按钮、复选框、状态 Tag 不触发；已归档记录行点击不选中 |
| 批量操作按钮 | `a-dropdown-button` | — | 主按钮“发布”，右侧为 `EllipsisOutlined` 下拉；下拉菜单依次为“归档”“删除”（危险样式）；无勾选时整体禁用 |

| 已选条数 | 文本 | — | 位于“取消选择”右侧，次要文字色，文案“已选 N 条”，随勾选实时更新，与“取消选择”同显同隐 |

#### 5.6.3 处理逻辑

1. 用户勾选复选框或点击行空白区域时更新选中记录；参与批量操作的记录在逻辑层再次排除已归档记录。
2. 点击“发布”：将选中记录全部置为 `published`（原为已发布的保持不变），展示成功反馈并清空选择，不需要确认。
3. 选择“归档”：展示二次确认；确认后将选中记录全部置为 `archived`，展示成功反馈并清空选择；取消时不修改记录、保留选择。
4. 选择“删除”：从选中记录中筛出草稿；没有草稿时只提示、不弹确认；有草稿时展示二次确认，确认后按 §5.5.3 第 2 步逐条移除草稿，展示成功反馈并清空选择；取消时不修改记录、保留选择。
5. 点击“取消选择”只清空选择，不修改业务数据。
6. 通过状态 Tag 将已选记录切换为已归档并确认后，该记录自动移出已选记录。
7. 点击“查询”或“重置”时清空已选记录（见 §5.1.3 第 7 步）。

#### 5.6.4 状态与规则

| 规则项 | 说明 |
| --- | --- |
| 可选择记录 | `draft`、`published`；`archived` 不可选择；已选记录被切换为已归档时自动移出已选记录 |
| 查询与重置 | 清空已选记录；批量操作只作用于当前查询结果中勾选的记录 |
| 批量发布 | 直接执行；计数为选中的未归档记录数 |
| 批量归档 | 必须二次确认；不可逆 |
| 批量删除 | 必须二次确认；只删除选中记录中的 `draft`，其余跳过并在确认弹窗中说明跳过条数 |
| 操作后选择状态 | 任一批量操作成功后清空选择，复选框与按钮恢复初始状态 |

#### 5.6.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 未勾选任何记录 | 批量操作按钮禁用 | 无额外 Toast |

| 选择批量归档 | 展示二次确认弹窗 | 标题：`确认归档已选择的 N 条记录？`；内容：`归档操作不可逆，请确认是否继续。` |

| 选择批量删除（选中记录均为草稿） | 展示二次确认弹窗 | 标题：`确认删除已选择的 N 条草稿记录？`；内容：`删除后不可恢复，请确认是否继续。` |

## 6. 接口与数据要求

> 当前阶段为原型，使用本地 Mock，不接入真实后端。

- **列表数据**：`src/mock/example.js` 导出响应式 `exampleList`（18 条种子记录），每条记录含 `id`、`name`、`category`、`groupKey`、`status`、`createTime`；`groupKey` 引用分组树任意层级节点的 `key`。示例列表与分组列表共用该数据。
- **分组数据**：`src/mock/example.js` 导出只读 `exampleGroupTree`（节点含唯一 `key`、`title`、可选 `children`），以及由分组树生成的 `exampleGroupPathMap`（`key` → 完整路径）；示例列表、分组列表与所属分组选择框统一使用该映射显示完整路径。
- **编号生成**：`nextExampleId()` 在前端样例中生成递增编号；真实项目应由后端生成。
- **共享枚举**：`src/mock/enums.js` 导出 `EXAMPLE_STATUS`、`EXAMPLE_CATEGORY`（`notice` 通知公告 / `activity` 活动资讯 / `policy` 制度文件）和枚举显示工具函数。
- **列表查询**：当前为前端内存筛选；接入接口后需传递名称、状态、分类数组、创建时间起止日期和分页参数。
- **分组列表查询**：接入接口后需传递分组 `key`、是否包含下级、名称、状态和分页参数；节点计数由后端按同一口径返回。
- **删除与批量操作**：当前为前端内存修改；接入接口后单条删除、批量删除、批量发布、批量归档均传递记录编号数组，由后端再次校验状态（删除仅限草稿、已归档不可参与），并返回实际处理条数。
- **数据持久化**：刷新页面后恢复初始 Mock 数据，本样例不承诺持久化。

## 9. 测试关注点

- **主流程验证**：查询提交、新建、编辑、删除、状态切换、批量发布 / 归档 / 删除和重置均形成完整反馈。

| SRS-AC-22 | 新建、编辑或快速编辑时名称只输入空格并保存 | 阻止保存，名称字段提示“请输入名称”，并提示“请完善必填项后再操作”；名称首尾带空格的合法输入保存后去除首尾空格 |
| SRS-AC-23 | 在示例列表或分组列表点击记录名称 | 打开“查看示例记录”只读弹窗，字段与 §5.2.2 查看弹窗一致，底部只有“关闭” |
| SRS-AC-24 | 勾选记录后点击“查询”或“重置” | 已选记录清空，“取消选择”与已选条数隐藏，“发布”下拉按钮禁用 |
| SRS-AC-25 | 新建、编辑或快速编辑时未选择所属分组并保存 | 阻止保存，所属分组字段提示“请选择所属分组”，并提示“请完善必填项后再操作”，页面滚动到第一个错误字段 |
| SRS-AC-26 | 在示例列表新建记录并选择所属分组“浦东站点”后，进入分组列表选中“浦东站点” | 列表包含该记录；“浦东站点”及其上级“上海分部”“华东区域”的计数（包含下级时）各加 1，“全部”计数加 1 |
