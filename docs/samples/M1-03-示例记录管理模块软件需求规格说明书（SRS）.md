## 4. 总体说明

> **业务背景与模块目标**：见 PRD §3～§5。

- **系统目标**：使用 Vue 3 与 Ant Design Vue 实现可运行的单页原型，并使字段、状态和反馈与本 SRS 一致。
- **关键约束**：
  - 查询条件采用编辑态与已提交态分离，输入过程不触发筛选。
  - 创建时间为默认排序字段，按时间倒序展示。
  - “已归档”为不可逆终态。
- **外部依赖**：当前原型只依赖本地 Mock 和共享枚举，无真实接口依赖。

## 5. 功能规格

### 5.1 示例记录查询

#### 5.1.1 功能描述

- **功能目标**：按名称和状态筛选示例记录，并支持一键恢复全量列表。
- **使用角色**：记录管理员、业务评审人。
- **入口位置**：左侧菜单“示例模块”→“示例列表”，路由 `/example/list`。
- **前置条件**：页面与本地 Mock 数据加载完成。

#### 5.1.2 页面与字段

**筛选字段**

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 名称 | `a-input` 文本输入 | 否 | 支持模糊匹配；宽度 200px；可清空 |
| 状态 | `a-select` 单选下拉 | 否 | 选项来自 `EXAMPLE_STATUS`；宽度 160px；可清空 |
| 查询 | `a-button` 主按钮 | — | 点击后提交当前筛选条件 |
| 重置 | `a-button` 默认按钮 | — | 清空编辑态和已提交态条件 |

#### 5.1.3 处理逻辑

1. 用户修改名称或状态时，只更新筛选编辑态，不改变当前列表。
2. 用户点击“查询”后，将名称去除首尾空格，并把名称、状态复制到已提交态。
3. 列表按已提交态执行名称模糊匹配和状态精确匹配。
4. 用户点击“重置”后，同时清空两套条件并恢复全量列表。
5. 筛选完成后按 `createTime` 倒序排列。

#### 5.1.4 状态与规则

| 规则项 | 说明 |
| --- | --- |
| 查询触发 | 仅点击“查询”后应用筛选条件 |
| 名称匹配 | 忽略英文字母大小写的包含匹配 |
| 空条件 | 名称为空且状态未选择时展示全部记录 |
| 默认排序 | `createTime` 从新到旧 |

#### 5.1.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 无匹配记录 | 表格展示 Ant Design Vue 默认空状态 | 无额外 Toast |
| 名称仅含空格 | 查询时按空名称处理 | 无额外 Toast |

---

### 5.2 示例记录新建与编辑

#### 5.2.1 功能描述

- **功能目标**：在近全屏弹窗内创建或编辑示例记录。
- **使用角色**：记录管理员。
- **入口位置**：列表卡右上角“新建”按钮或记录行“编辑”按钮。
- **前置条件**：用户进入示例列表页面。

#### 5.2.2 页面与字段

**列表展示字段**

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 编号 `id` | 只读文本 | — | 新建时由 `nextExampleId()` 生成，格式为 `EX-2026-NNNN` |
| 名称 `name` | 文本 | 是 | 列表展示记录名称 |
| 状态 `status` | Tag | 是 | 标签和值来自 `EXAMPLE_STATUS` |
| 创建时间 `createTime` | 日期时间文本 | 是 | 新建时取本地当前时间，格式 `YYYY-MM-DD HH:mm:ss` |

**新建与编辑表单字段**

| 字段/控件 | 控件类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 名称 | `a-input` | 是 | 最大 50 字；失焦时校验；占位文案“请输入名称” |
| 状态（新建） | 只读 `a-tag` | 是 | 默认“草稿”，提示“新建记录默认状态，不可修改” |
| 状态（编辑非归档记录） | `a-select` | 是 | 只提供“草稿”“已发布”，归档必须从列表状态入口执行 |
| 状态（编辑已归档记录） | 只读 `a-tag` | 是 | 提示“已归档记录状态不可修改” |

#### 5.2.3 处理逻辑

1. 点击“新建”时清空名称、设置状态为 `draft`，并打开“新建示例记录”弹窗。
2. 点击“编辑”时按记录编号回填名称和状态，并打开“编辑示例记录”弹窗。
3. 点击“保存”时调用表单校验。
4. 新建校验通过后生成编号和创建时间，将记录加入 Mock 列表。
5. 编辑校验通过后按编号查找原记录并更新名称和允许编辑的状态。
6. 保存成功后关闭弹窗；列表重新计算并保持创建时间倒序。

#### 5.2.4 状态与规则

| 规则项 | 说明 |
| --- | --- |
| 新建默认状态 | `draft`，中文显示“草稿” |
| 新建编号 | 从 `EX-2026-0011` 起按四位序号递增 |
| 弹窗关闭 | 关闭时重置字段和校验状态 |
| 归档入口 | 编辑表单不提供“已归档”选项，统一从列表状态标签进入 |
| 归档终态 | 已归档记录的状态只读，不允许回退 |

#### 5.2.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 名称为空 | 阻止保存并展示字段级错误 | `请输入名称` |
| 名称超过 50 字 | 输入层限制长度，校验层再次拦截 | `名称不超过 50 字` |
| 表单校验失败 | 展示 Toast，并滚动到第一个错误字段 | `请完善必填项后再操作` |
| 保存成功 | 关闭弹窗并刷新列表 | `保存成功` |

### 5.3 示例记录状态管理

#### 5.3.1 功能描述

- **功能目标**：通过状态 Tag 识别当前状态，并完成允许的状态切换。
- **使用角色**：记录管理员。
- **入口位置**：示例列表“状态”列。
- **前置条件**：记录当前状态不是“已归档”。

#### 5.3.2 页面与字段

| 字段/控件 | 类型 | 是否必填 | 规则说明 |
| --- | --- | --- | --- |
| 状态 Tag | `a-tag` | — | 草稿为蓝色、已发布为绿色、已归档为默认灰色 |
| 切换提示图标 | `SwapOutlined` | — | 仅可切换状态显示；字号 11px、透明度 0.7 |
| 状态菜单 | `a-dropdown` + `a-menu` | — | 排除当前状态后展示其他可选状态 |

#### 5.3.3 处理逻辑

1. 草稿或已发布记录显示可点击 Tag 和切换图标。
2. 点击 Tag 后展示除当前状态外的目标状态。
3. 选择草稿或已发布时直接更新状态并反馈结果。
4. 选择已归档时展示二次确认。
5. 用户确认后更新为已归档；用户取消时不改变状态。
6. 已归档记录只展示普通 Tag，不渲染下拉菜单和切换图标。

#### 5.3.4 状态与规则

| 状态值 | 中文文案 | Tag 颜色 | 可切换目标 | 规则 |
| --- | --- | --- | --- | --- |
| `draft` | 草稿 | blue | 已发布、已归档 | 可直接发布；归档需确认 |
| `published` | 已发布 | green | 草稿、已归档 | 可直接退回草稿；归档需确认 |
| `archived` | 已归档 | default | 无 | 不可逆终态 |

#### 5.3.5 异常处理

| 异常场景 | 处理方式 | 提示信息 |
| --- | --- | --- |
| 选择归档 | 展示二次确认弹窗 | 标题：`确认将「记录名称」切换为「已归档」？`；内容：`归档操作不可逆，请确认是否继续。` |
| 取消归档 | 关闭确认弹窗，不修改记录 | 无额外 Toast |
| 状态切换成功 | 更新状态并展示成功反馈 | `已切换为` + 目标状态中文文案 + `状态` |
| 试图切换已归档记录 | 界面不提供入口；逻辑层直接返回 | 无额外 Toast |

## 6. 接口与数据要求

> 当前阶段为原型，使用本地 Mock，不接入真实后端。

- **列表数据**：`src/mock/example.js` 导出响应式 `exampleList`。
- **编号生成**：`nextExampleId()` 在前端样例中生成递增编号；真实项目应由后端生成。
- **共享枚举**：`src/mock/enums.js` 导出 `EXAMPLE_STATUS` 和枚举显示工具函数。
- **列表查询**：当前为前端内存筛选；接入接口后需传递名称、状态和分页参数。
- **数据持久化**：刷新页面后恢复初始 Mock 数据，本样例不承诺持久化。

## 7. 权限与安全要求

| 角色 | 查询 | 新建 | 编辑 | 状态切换 |
| --- | --- | --- | --- | --- |
| 记录管理员 | 允许 | 允许 | 允许 | 允许 |
| 业务评审人 | 允许 | 不允许 | 不允许 | 不允许 |

- 当前原型未实现登录和权限拦截，仅通过文档声明权限边界。
- Mock 数据不得出现真实人员、客户、联系方式或生产凭据。
- 归档操作必须二次确认，已归档状态不得恢复。

---

## 8. 非功能需求

- **性能要求**：1000 条以内本地记录查询结果在 2 秒内完成更新。
- **稳定性要求**：重复查询、重置、打开和关闭弹窗不得产生页面错误或重复记录。
- **可用性要求**：查询与重置按钮始终可见；可切换状态必须显示切换图标；校验失败可定位到字段。
- **兼容性要求**：支持当前主流桌面版 Chrome 与 Edge；本期不要求移动端适配。

---

## 9. 测试关注点

- **主流程验证**：查询提交、新建、编辑、状态切换和重置均形成完整反馈。
- **权限验证**：接入真实权限后，无维护权限角色不得看到写操作入口。
- **数据验证**：编号不重复，创建时间格式正确，列表保持时间倒序。
- **异常验证**：空名称、超长名称、无查询结果、取消归档、已归档状态不可回退。
- **回归关注点**：输入筛选条件时列表不得提前变化；筛选卡内边距不得重复覆盖。

## 10. 验收标准

| 编号 | 触发条件 | 系统预期结果 |
| --- | --- | --- |
| SRS-AC-01 | 输入“记录十”但尚未点击“查询” | 列表保持原结果；点击“查询”后只展示名称匹配记录 |
| SRS-AC-02 | 已应用任意筛选条件后点击“重置” | 名称和状态条件清空，列表恢复全部记录并保持时间倒序 |
| SRS-AC-03 | 新建时填写合法名称并保存 | 生成唯一编号和创建时间，默认状态为草稿，提示“保存成功” |
| SRS-AC-04 | 新建或编辑时名称为空并保存 | 阻止保存，字段显示错误，并提示“请完善必填项后再操作” |
| SRS-AC-05 | 点击草稿或已发布状态 Tag | Tag 显示切换图标，菜单排除当前状态并展示其他目标状态 |
| SRS-AC-06 | 选择已归档并确认 | 状态更新为已归档，提示切换成功；此后不再显示切换入口 |
