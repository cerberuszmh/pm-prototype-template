## 3. 编写目的

- **本文档目标**：明确示例记录管理模块的业务目标、范围、角色、流程及业务验收口径。
- **本模块需求解决的问题**：
  1. 记录管理员需要快速定位目标记录。
  2. 记录管理员需要在统一入口完成记录创建、编辑和状态维护。
  3. 模板学习者需要理解业务需求与技术规格的分工。
- **面向的评审对象**：产品负责人、业务评审人、开发与测试人员。

## 4. 需求背景

- **模块业务背景**：现有模板只有空文档骨架，缺少一套能与页面行为相互对照的模块成品。
- **当前痛点**：使用者容易把字段类型、校验和精确提示文案写进 PRD，造成 PRD 与 SRS 重复维护。
- **触发原因**：需要通过一个最小记录管理场景展示业务文档、技术规格和原型之间的正确关系。
- **相关系统/模块**：项目级约束见 P07 §9～§12；本样例无其他业务模块依赖。

## 5. 模块目标

- **模块业务目标**：让记录管理员能够完成示例记录的查询、创建、编辑、删除和状态管理，并能对多条记录统一处理。
- **用户目标**：在一个列表页面内完成高频记录维护，不依赖多个页面来回跳转。
- **成功指标**：首次接触模板的 PM 能根据本样例区分 PRD 与 SRS 的内容归属，并完成同结构文档。

## 6. 范围说明

### 6.1 本模块范围

- 按记录名称、状态、分类和创建时间范围查询。
- 新建示例记录。
- 编辑示例记录的名称、分类、所属分组和状态。
- 查看状态并执行允许的状态切换。
- 对不可逆归档操作进行二次确认。
- 删除草稿状态的示例记录，删除前二次确认。
- 勾选多条记录后批量发布、批量归档、批量删除。
- 通过分组层级（区域 / 分部 / 站点）限定查看范围，浏览示例记录。

### 6.2 非本模块范围

- 登录、组织与角色配置。
- 导入和导出。
- 真实后端接口、数据库与部署。

## 7. 角色与用户

| 角色 | 场景描述 | 核心诉求 |
| --- | --- | --- |
| 记录管理员 | 日常维护示例记录 | 快速找到记录并完成创建、编辑和状态调整 |
| 业务评审人 | 核对页面是否符合业务规则 | 确认流程、术语和反馈语义一致 |

> 全局角色与权限模型见 P07 §2、§5；详细权限矩阵见 SRS §7。

## 8. 业务流程概述

### 8.1 主流程

1. 记录管理员进入“示例列表”页面。
2. 记录管理员设置名称、状态、分类或创建时间等查询条件，点击“查询”。
3. 系统展示符合条件的记录，并保持创建时间较新的记录在前。
4. 记录管理员可新建记录或编辑已有记录。
5. 记录管理员可通过状态标签选择新的状态；归档操作确认后生效。
6. 记录管理员可删除草稿记录；删除确认后生效。
7. 记录管理员可勾选多条记录，统一发布、归档或删除；归档和删除确认后生效。
8. 记录管理员或业务评审人可进入“分组列表”，选定分组范围后浏览该范围内的记录。

### 8.2 异常流程

| 业务异常场景 | 业务侧处理建议 |
| --- | --- |
| 新建或编辑时必填信息不完整 | 阻止保存，并提示用户补充必要信息 |
| 用户误触归档 | 在执行前展示二次确认，允许取消 |
| 用户误触删除 | 在执行前展示二次确认，允许取消 |
| 试图删除已发布或已归档记录 | 不允许删除，并说明仅草稿可删除 |
| 批量删除时勾选了非草稿记录 | 只删除其中的草稿，确认前告知将跳过的条数 |
| 查询无匹配记录 | 展示空结果，不改变已输入的查询条件 |

> 详细技术异常处置及提示文案见 SRS §5.2.5、§5.3.5、§5.5.5、§5.6.5。

## 9. 功能需求明细

### 9.1 示例记录查询

#### 9.1.1 业务目标

- **解决问题**：帮助记录管理员从列表中快速定位目标记录。
- **目标角色**：记录管理员、业务评审人。
- **使用场景**：按名称模糊查找，按状态精确筛选，按单一分类筛选，或按创建日期区间筛选。

#### 9.1.2 业务功能与字段

| 字段名 | 业务用途 |
| --- | --- |
| 名称 | 识别记录并作为查询条件 |
| 状态 | 判断记录所处业务阶段并作为查询条件 |
| 分类 | 区分记录的内容类型，作为单选查询条件 |
| 创建时间 | 判断记录新旧顺序，并可按日期区间查询 |

> **完整字段规格**：见 SRS §5.1.2 页面与字段。

#### 9.1.3 业务规则

- 输入筛选条件不会立即改变结果，点击“查询”后统一应用。
- 选择某一分类时，仅展示该分类的记录；未选择时不按分类筛选。
- 创建日期区间包含起止当天。
- 点击“重置”后清空筛选条件并恢复全部记录。
- 默认按创建时间从新到旧展示。

#### 9.1.4 业务侧关键交互

| 业务操作 | 业务侧期望反馈 |
| --- | --- |
| 点击查询 | 展示符合当前条件的记录 |
| 点击重置 | 清空条件并恢复全量列表 |

> **完整交互规格**：见 SRS §5.1.3 处理逻辑。

### 9.2 示例记录维护

#### 9.2.1 业务目标

- **解决问题**：在统一入口完成记录创建和编辑。
- **目标角色**：记录管理员。
- **使用场景**：创建新记录或修正已有记录信息。

#### 9.2.2 业务功能与字段

| 字段名 | 业务用途 |
| --- | --- |
| 编号 | 唯一识别一条示例记录 |
| 名称 | 描述记录的业务名称 |
| 分类 | 标明记录属于通知公告、活动资讯或制度文件 |
| 所属分组 | 标明记录归属的区域、分部或站点，供分组列表按层级浏览 |
| 状态 | 表示记录当前业务阶段 |
| 创建时间 | 记录创建时点并支持默认排序 |

> **完整字段规格与校验规则**：见 SRS §5.2.2 页面与字段。

#### 9.2.3 业务规则

- 新建记录时由系统生成编号和创建时间。
- 新建记录的默认状态为“草稿”。
- 每条记录必须归属一个分类。
- 每条记录必须归属一个分组，可以是区域、分部或站点中的任意一级。
- 编辑记录时允许修改名称、分类、所属分组和状态。

#### 9.2.4 业务侧关键交互

| 业务操作 | 业务侧期望反馈 |
| --- | --- |
| 保存有效记录 | 告知用户保存结果并关闭编辑窗口 |
| 保存信息不完整的记录 | 阻止保存并引导用户修正 |
| 点击记录名称 | 只读查看该记录的全部信息 |

> **完整交互与反馈细节**：见 SRS §5.2.3、§5.2.5。

### 9.3 示例记录状态管理

#### 9.3.1 业务目标

- **解决问题**：让管理员直观看到并维护记录所处阶段。
- **目标角色**：记录管理员。
- **使用场景**：从状态标签进入状态切换操作。

#### 9.3.2 业务功能与字段

| 字段名 | 业务用途 |
| --- | --- |
| 状态 | 展示记录当前阶段，并作为状态切换入口 |

> **完整状态规格**：见 SRS §5.3.2、§5.3.4。

#### 9.3.3 业务规则

- 可选目标状态不重复展示当前状态。
- 归档属于不可逆操作，确认后不能再次切换。
- 非归档状态切换确认选择后直接生效。

#### 9.3.4 业务侧关键交互

| 业务操作 | 业务侧期望反馈 |
| --- | --- |
| 点击状态标签 | 展示可切换的其他状态 |
| 选择归档 | 要求再次确认后执行 |
| 完成状态切换 | 明确告知切换结果 |

> **完整状态机和提示文案**：见 SRS §5.3.3～§5.3.5。

### 9.4 分组列表

#### 9.4.1 业务目标

- **解决问题**：让用户按组织层级缩小查看范围，快速聚焦某个区域、分部或站点的记录。
- **目标角色**：记录管理员、业务评审人。
- **使用场景**：先在分组层级中选定范围，再按名称或状态进一步查找。

#### 9.4.2 业务功能与字段

| 字段名 | 业务用途 |
| --- | --- |
| 分组层级 | 以区域 / 分部 / 站点组织记录，并显示各分组的记录数量 |
| 包含下级 | 决定选中分组时是否一并查看其全部下级分组的记录 |
| 所属分组 | 说明记录归属的完整分组路径 |
| 名称、状态、创建时间 | 识别记录、判断阶段与新旧顺序 |

> **完整字段规格**：见 SRS §5.4.2 页面与字段。

#### 9.4.3 业务规则

- 默认查看全部记录；选中分组后立即只看该分组范围内的记录。
- 默认包含下级，选中区域即可看到其下全部分部和站点的记录。
- 可通过分组搜索按名称快速找到深层分组；分组搜索只过滤分组层级，不改变记录查询条件。
- 本页面只用于浏览，不提供新建、编辑和状态切换。
- 分组列表与示例列表展示的是同一批示例记录；在示例列表中维护的结果（含调整所属分组）同步体现在分组列表。

#### 9.4.4 业务侧关键交互

| 业务操作 | 业务侧期望反馈 |
| --- | --- |
| 点击分组 | 列表立即切换为该分组范围的记录 |
| 再次点击已选分组或点击“全部” | 恢复查看全部记录 |
| 切换“包含下级” | 分组数量与列表结果同步变化 |

> **完整交互规格**：见 SRS §5.4.3～§5.4.5。

### 9.5 示例记录删除

#### 9.5.1 业务目标

- **解决问题**：清理误建或不再需要的草稿，避免无效记录干扰查询。
- **目标角色**：记录管理员。
- **使用场景**：在示例列表中对某条草稿记录直接执行删除。

#### 9.5.2 业务功能与字段

| 字段名 | 业务用途 |
| --- | --- |
| 状态 | 判断记录是否允许删除 |
| 名称 | 删除确认时告知用户将要删除的记录 |

> **完整字段与控件规格**：见 SRS §5.5.2 页面与字段。

#### 9.5.3 业务规则

- 只有草稿记录可以删除；已发布记录已对外生效、已归档记录已终止，删除会丢失业务痕迹，因此不允许删除。
- 删除后记录不可恢复，执行前必须二次确认。
- 删除与归档是不同动作：归档保留记录，删除将记录从列表中移除。

#### 9.5.4 业务侧关键交互

| 业务操作 | 业务侧期望反馈 |
| --- | --- |
| 删除草稿记录 | 要求再次确认，确认后记录从列表中移除并告知结果 |
| 查看非草稿记录的删除入口 | 入口不可用，并说明仅草稿可删除 |

> **完整交互与反馈细节**：见 SRS §5.5.3～§5.5.5。

### 9.6 批量操作

#### 9.6.1 业务目标

- **解决问题**：一次处理多条记录，减少逐条发布、归档或删除的重复操作。
- **目标角色**：记录管理员。
- **使用场景**：勾选多条记录后统一发布、归档或删除。

#### 9.6.2 业务功能与字段

| 字段名 | 业务用途 |
| --- | --- |
| 选择状态 | 标明哪些记录参与本次批量操作 |
| 已选条数 | 执行前让用户确认处理范围 |
| 状态 | 决定记录能否被选择、能否被批量删除 |

> **完整字段与控件规格**：见 SRS §5.6.2 页面与字段。

#### 9.6.3 业务规则

- 已归档记录不能被选择，不参与任何批量操作。
- 批量发布无需确认，直接生效；批量归档和批量删除执行前必须二次确认。
- 批量删除只删除所选记录中的草稿；其余记录跳过，并在确认前告知跳过条数；所选记录中没有草稿时不执行删除并给出提示。
- 批量操作完成后清空选择，避免误对同一批记录重复操作。
- 重新查询或重置查询条件后清空选择，避免对当前列表之外的记录误操作。
- 记录被归档后自动退出选择范围。

#### 9.6.4 业务侧关键交互

| 业务操作 | 业务侧期望反馈 |
| --- | --- |
| 未选择任何记录 | 批量操作入口不可用 |
| 勾选记录 | 实时显示已选条数，并可一键取消选择 |
| 执行批量操作 | 告知处理条数，并清空选择 |

> **完整交互与反馈细节**：见 SRS §5.6.3～§5.6.5。

## 10. 业务级非功能要求（模块特有）

- **业务侧响应预期**：用户执行查询或状态切换后应立即得到明确结果。
- **业务侧权限边界**：仅记录管理员可以创建、编辑、删除、切换状态和执行批量操作。
- **业务侧日志与审计要求**：本教学原型不落真实审计日志，正式项目应由项目级要求决定。
