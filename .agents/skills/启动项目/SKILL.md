# 启动项目

> 本 SKILL 不保存项目绝对路径或 Cursor 项目 hash。每次执行时从当前工作区上下文动态取得项目根目录与终端目录，模板复制后无需人工修改本文件。

## 操作步骤

1. 从 Cursor 当前会话提供的工作区信息取得项目根目录；禁止猜测或把路径写回本 SKILL。
2. 从当前会话提供的终端目录检查运行状态：
   - 用专用文件查找工具列出终端状态文件；
   - 用专用读取工具检查是否已有 `npm run dev` / `vite` 进程，禁止用 Shell 读取文件内容；
   - 终端目录为空时视为未运行。
3. 若已运行且输出包含可访问的本地地址，直接告知用户该地址，不重复启动。
4. 若未运行，以当前工作区根目录作为 `working_directory` 执行：

```text
命令：npm run dev
block_until_ms：8000（等待 Vite 就绪后转入后台）
```

5. 启动后确认输出中出现 `Local:`；向用户返回实际地址，不默认假定端口一定是 5173。

## 项目信息

- 项目根目录：运行时从当前工作区上下文读取
- 终端目录：运行时从当前会话上下文读取
- 默认开发服务器端口：`5173`（由 Vite 默认配置）
- 启动命令：`npm run dev`
