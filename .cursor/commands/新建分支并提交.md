# 新建分支并提交

基于当前分支新建一个分支，把当前工作区的全部改动提交到新分支，并推送到远程仓库。

命令后附带的文字作为分支名或分支用途说明，例如 `/新建分支并提交 feature/ai-panel`。

## 执行步骤

1. 运行 `git status --short`、`git branch --show-current`，确认当前分支与改动文件。
2. 确定分支名：
   - 用户已给出合法分支名时直接使用。
   - 用户只给出用途说明或未提供时，按 `类型/英文短横线描述` 格式（如 `feature/ai-panel`、`fix/scrollbar`）给出建议名称，**停止并等待用户确认**后再继续。
   - 分支名与本地或远程已有分支重名时，停止并请用户另起名称。
3. 检查是否包含不应提交的内容：密钥、口令、令牌、`.env` 类文件、超大二进制文件。发现可疑内容时立即停止，列出文件并等待用户确认。
4. 执行 `git switch -c 新分支名`，未提交的改动随之带到新分支。
5. 根据改动内容撰写中文提交说明：
   - 标题使用 `类型: 一句话说明`，类型取 `feat` / `fix` / `docs` / `style` / `refactor` / `chore`。
   - 正文用短列表概括主要改动，按业务语义描述，不罗列文件名。
6. 执行 `git add -A`、`git commit`，再执行 `git push -u origin 新分支名`，建立与远程分支的关联。
7. 运行 `git status`，确认工作区干净、新分支已与远程同步。

## 约束

- 禁止使用 `--force`、`--force-with-lease` 等强制推送参数。
- 不合并、不删除任何分支，不修改原分支。
- 无任何改动时，只新建分支并推送，并在反馈中说明本次没有新提交。

## 完成后反馈

用中文简要说明：新分支名、提交编号与标题、远程分支地址，并提示可在 GitHub 上基于该分支创建合并请求。
