## 5. 命名映射约定

### 5.1 命名规则

- **中文字段名**：与 SRS §5.x.2 完全一致，禁止改叫法
- **前端字段名**：camelCase（如 `projectName`、`buildingArea`），布尔字段以 `is` 开头
- **后端字段名**：snake_case（如 `project_name`、`building_area`），与数据库列名建议一致
- **枚举码**：UPPER_SNAKE_CASE（如 `UNDER_CONSTRUCTION`、`COMPLETED`）

### 5.2 跨字段一致性约束

| 约束项 | 规则 |
|---|---|
| 金额字段单位 | 前端展示与后端存储均以"万元"为单位，禁止单位混用 |
| 日期字段格式 | 前端 `value-format="YYYY-MM-DD"`，后端 ISO 8601 字符串或时间戳 |
| 手机号字段长度 | 前端 `:maxlength="11"`，后端 string(11) |
| 多选字段传值 | 前端使用数组（如 `["MIN_SHENG", "ZHONG_DIAN"]`），后端建议存为 JSON 数组或关联表 |

## 6. 字典维护规则

<!-- 数据字典是派生文档，必须随 SRS 升级而同步升级 -->

1. **SRS 字段变更时**：本字典必须在同一对话内同步升级，不得脱节
2. **字典变更须留痕**：在元信息表"最近更新日期"中记录，并在 §1 后追加"变更摘要"行
3. **不得在本字典内引入新业务规则**：如发现需要新增规则，应回 SRS 增补，本字典再同步
4. **冲突处理**：本字典与 SRS 不一致时，以 SRS 为准并立即修正本字典
