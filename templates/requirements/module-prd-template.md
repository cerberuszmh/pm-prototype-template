# {模块名} 产品需求文档（PRD · 模块级）

> **文档定位**：本模板按 `.cursor/rules/doc-format.mdc §"项目级 PRD vs 模块级 PRD 分工"` 规则定义为**模块级 PRD**（每个功能模块一份），回答本模块"做什么 + 为什么 + 给谁用"。归档命名为 `docs/formal-requirements/M{n}-02-{模块名}模块产品需求文档（PRD）.md`。
>
> **层级区分**：项目级 PRD（系统全局一份）请改用 `templates/requirements/project-prd-template.md`；两套编号体系相互独立，禁止混用。
>
> **职责边界**：
>
> - ✅ 本模块级 PRD 维护：本模块的需求背景、角色场景、模块范围、业务流程、业务规则简述、业务级验收、待确认清单
> - ❌ 不维护（技术规格）：字段类型/校验规则、AC 验收技术清单、接口规格、非功能技术指标、状态机细节 —— 唯一权威源是 **SRS**，需要时按"详见 SRS §X.X"格式引用
> - ❌ 不重复（项目级内容）：项目背景/总体目标、项目级非功能需求、项目级权限模型、项目级验收里程碑 —— 唯一权威源是**项目级 PRD（P07）**，需要时按"详见 P07 §X"格式引用
>
> **重叠率上限**：本 PRD 与对应 SRS 内容重叠率须 ≤ 15%，超出视为违规。
